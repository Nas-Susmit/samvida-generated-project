# User Stories for MyProject


- **1**: As a **User**, I want to **Enter daily food intake** so that **To track calorie consumption accurately** (Priority: High)

- **2**: As a **User**, I want to **Set daily calorie goals** so that **To receive personalized dietary recommendations** (Priority: Medium)

- **3**: As a **Admin**, I want to **Manage food database** so that **To ensure accurate calorie information for users** (Priority: Low)

- **4**: As a **User**, I want to **View progress reports** so that **To monitor calorie intake and stay motivated** (Priority: High)

- **5**: As a **User**, I want to **Recieve nutrition advice** so that **To make informed decisions about diet and health** (Priority: Medium)
