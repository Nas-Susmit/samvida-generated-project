# User Stories for MyProject


- **SC-001**: As a **User**, I want to **perform basic arithmetic operations like addition, subtraction, multiplication, and division** so that **calculate simple mathematical expressions accurately.** (Priority: High)

- **SC-002**: As a **User**, I want to **group operations using parentheses** so that **control the order of calculations for complex expressions and ensure correct results.** (Priority: High)

- **SC-003**: As a **Engineering Student**, I want to **calculate sine, cosine, and tangent for a given angle in degrees or radians** so that **solve problems involving angles and triangles in my coursework and projects.** (Priority: Medium)

- **SC-004**: As a **Scientist**, I want to **calculate the square root and raise a number to a power (e.g., x^y)** so that **quickly perform common scientific computations without manual calculations.** (Priority: Medium)

- **SC-005**: As a **User**, I want to **clear the current entry or reset all calculations** so that **correct mistakes easily or start a new calculation without re-opening the calculator.** (Priority: High)

- **SC-006**: As a **Mathematician**, I want to **input the mathematical constants Pi (π) and Euler's number (e)** so that **use precise constant values in my calculations without manual entry.** (Priority: Low)
