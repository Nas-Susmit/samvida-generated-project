# User Stories for MyProject


- **ATS-001**: As a **Job Seeker**, I want to **upload my resume and a target job description** so that **get an immediate compatibility score and initial feedback on how well they match** (Priority: High)

- **ATS-002**: As a **Job Seeker**, I want to **see a list of keywords from the job description that are missing or underrepresented in my resume** so that **easily identify areas to optimize my resume for better ATS matching** (Priority: High)

- **ATS-003**: As a **Job Seeker**, I want to **receive suggestions on common formatting issues (e.g., non-standard fonts, complex tables) that might confuse an ATS** so that **ensure my resume is easily parsable by automated systems** (Priority: High)

- **ATS-004**: As a **Job Seeker**, I want to **view a comparison of my skills listed in my resume against the required skills in the job description** so that **understand my skill gaps and tailor my resume more effectively** (Priority: Medium)

- **ATS-005**: As a **Job Seeker**, I want to **get a detailed breakdown of my resume's ATS-friendliness score across different categories (e.g., keywords, formatting, length)** so that **understand specific areas where my resume can be improved for ATS success** (Priority: Medium)
