# User Stories for MyProject


- **US1**: As a **As a user**, I want to **I want to create a new task with a title and description** so that **so I can keep track of what I need to do.** (Priority: High)

- **US2**: As a **As a user**, I want to **I want to set a due date for a task** so that **so I can prioritize my work and meet deadlines.** (Priority: High)

- **US3**: As a **As a user**, I want to **I want to mark a task as complete** so that **so I can see my progress and know what's finished.** (Priority: High)

- **US4**: As a **As a user**, I want to **I want to organize tasks into projects** so that **so I can group related tasks and manage larger goals effectively.** (Priority: Medium)
