# User Stories for MyProject


- **1**: As a **User**, I want to **Enter daily food consumption** so that **To track calorie intake** (Priority: High)

- **2**: As a **User**, I want to **Select meal type (breakfast, lunch, dinner, snack)** so that **To categorize calorie intake** (Priority: Medium)

- **3**: As a **User**, I want to **View total daily calorie intake** so that **To monitor progress towards dietary goals** (Priority: High)

- **4**: As a **User**, I want to **Set and track daily calorie goals** so that **To achieve and maintain a healthy weight** (Priority: High)

- **5**: As a **Admin**, I want to **Maintain a database of common foods and their calorie counts** so that **To provide accurate calorie calculations for users** (Priority: Low)

- **6**: As a **User**, I want to **Save and view calorie intake history** so that **To identify trends and patterns in eating habits** (Priority: Medium)
