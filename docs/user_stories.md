# User Stories for MyProject


- **1**: As a **User**, I want to **Enter daily food intake** so that **To track calories consumed** (Priority: High)

- **2**: As a **Admin**, I want to **Configure food database** so that **To provide accurate calorie information** (Priority: Medium)

- **3**: As a **User**, I want to **Set daily calorie goals** so that **To receive personalized recommendations** (Priority: High)

- **4**: As a **User**, I want to **View progress reports** so that **To monitor calorie intake over time** (Priority: Medium)

- **5**: As a **User**, I want to **Receive recipe suggestions** so that **To discover healthy meal options** (Priority: Low)

- **6**: As a **Admin**, I want to **Maintain user accounts** so that **To ensure secure access to user data** (Priority: High)
