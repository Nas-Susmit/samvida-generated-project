# User Stories for MyProject


- **1**: As a **User**, I want to **Enter numbers** so that **To perform calculations** (Priority: High)

- **2**: As a **User**, I want to **Select arithmetic operations** so that **To get the desired results** (Priority: High)

- **3**: As a **User**, I want to **View calculation history** so that **To keep track of previous calculations** (Priority: Medium)

- **4**: As a **User**, I want to **Clear calculator input** so that **To start new calculations easily** (Priority: Low)

- **5**: As a **User**, I want to **Save favorite calculations** so that **To quickly access frequently used calculations** (Priority: Medium)

- **6**: As a **Admin**, I want to **Update calculator with new functions** so that **To improve user experience with advanced calculations** (Priority: High)
